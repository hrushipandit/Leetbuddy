How to run the project on your local Machine

1) Download and extract the file in a folder from the main branch.
2) Open a terminal in the leetbud directory, run the 'docker-compose up' command.
3) The frontend runs on https:localhost/3000 and the backend on https:localhost/5000

The production code is available on the EC2-deployment branch, the website is live on https://www.leetbud.com
